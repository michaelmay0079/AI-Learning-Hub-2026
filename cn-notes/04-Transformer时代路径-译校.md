# 译校 · Transformer 时代学习路径（改编）

> **原文**：[Learning path: The transformer era](https://ai.miraheze.org/wiki/Learning_path:_The_transformer_era)（AI Wiki）。
> **说明**：本篇为其中文**译校/改编**，梳理"从词向量到大模型助手"的概念演进序列；版权归原作者。核验日期：2026-11-09。

## 这条路径在讲什么

它沿着"注意力（attention）"这一思想的来龙去脉，从 2017 的 Transformer，经 BERT/GPT 两脉、缩放定律，一直走到把大模型交到每个人手里的系统。下面是其节点精缩版。

## 概念演进序列（精缩）

1. **NLP（自然语言处理）**：让机器处理语言的领域，是 Transformer 改变的对象。
2. **分词（Tokenization）**：文本如何变成模型能读的单位——模型从不见单个字母，记忆以 token 计。
3. **嵌入（Embedding）**：词/句变成"地图上的坐标"，距离即相似度（意义即几何）。
4. **LSTM**：Transformer 之前的主力，逐 token 读并携带记忆——强大但天然串行，瓶颈解释了为何注意力是突破。
5. **注意力（Attention）**：让模型对每个词决定"该看哪些其他词"，解决了串行瓶颈。
6. **Transformer（2017）**：纯注意力架构，并行、可扩展、通用——几乎现代所有语言模型的底座。
7. **自注意力（Self-Attention）**：每个 token 并行关注所有其他 token；理解它，就能看懂绝大多数 Transformer 图。
8. **BERT（Encoder 脉）**：双向理解，横扫理解类基准，证明"预训练+微调"范式。
9. **GPT（Decoder 脉）**：预测下一个 token，规模越大越通用——现代大模型的配方。
10. **GPT-3（2020）**：175B 参数，少样本/零样本显现"规模化质变"。
11. **缩放定律（Scaling Laws）**：模型大小、数据、算力与性能可预测相关——前沿进步一度像工程排期。
12. **大模型（LLM）**：前述步骤的合成——是什么、怎么训练与对齐、能/不能做什么。
13. **微调（Fine-tuning）**：用精选样本把"文本预测器"变成"有用专家"。
14. **ChatGPT（2022）**：几周之内把大模型带给数亿人，重置整个行业野心。
15. **GPT-4（2023）**：多模态、能力跃升的后 ChatGPT 时代标杆。
16. **MoE（混合专家）**：只对每个 token 激活超大模型的一小部分——近期前沿模型多用此思路。

## 给非从业者的用法

把这条序列当成"演进轴"：遇到任何新名词，先判断它在轴的哪一段（架构 / 规模化 / 对齐 / 应用），就不会被孤立术语吓住。本仓库[时间轴](timeline.md)与这条路径同源。
