> **说明**：本篇为其中文**译校/改编**，尽量完整走读 Transformer 核心机制；版权归原作者。核验日期：2026-11-09。

## 一、两种形态一句话

- **编码器（Encoder）**：读入并"理解"输入语义，常见于 BERT 类"理解模型"（分类、检索、填空）。
- **解码器（Decoder）**：基于已生成内容"生成"下一段，常见于 GPT 类"生成模型"（对话、写作）。
- 原始 2017 论文是 Encoder–Decoder（翻译）；今天的对话模型多为纯 Decoder。

## 二、一个词如何变成向量

文本先分词（token），每个 token 映射成一个**嵌入向量（Embedding）**——在"意义地图"上，距离近 = 语义近（意义即几何）。

## 三、自注意力：Transformer 的"灵魂"

一句话：**自注意力 = 让每个词计算它与其他所有词的关联强度，再按权重把信息聚合回来**。

通俗例子：句子"机器人打开了房门，它走进了房间"。模型处理"它"时，自动计算与"机器人""房门""房间"的关联权重，最终把"它"指向"机器人"，完成语义消歧。这正是大模型能读懂上下文、理解逻辑的核心。

## 四、Q / K / V 与分数怎么来（直觉版）

每个词生成三组向量：
- **Query（查询）**：我在找什么？
- **Key（键）**：我这里有什么？
- **Value（值）**：我携带什么信息？

做法：用"它"的 Query 去和句中每个词的 Key 做匹配（点积），得到"该关注谁"的原始分数 → 缩放（除以 √d）→ Softmax 归一化为权重 → 用权重混合各词的 Value。输出就是"被上下文重新表示过的'它'"。

## 五、多头注意力（Multi-Head）

不是只算一组 Q/K/V，而是**并行跑多组**，每组学不同视角（语法、语义、长距指代……），最后拼接。这些"视角"是训练出来的，而非人指定——模型自己发现"有组专门看指代、有组专门看语法"。

## 六、位置编码

注意力本身"无顺序感"：把词序打乱，结果一样（"狗咬人"与"人咬狗"对它最初是同一堆词）。因此必须额外注入**位置信号**——现代模型常用旋转位置编码（RoPE）一类方法，把"第几个词"编进向量。

## 七、Transformer 块与堆叠

一个块 = **自注意力 → 残差+层归一化 → 前馈网络 → 残差+层归一化**。残差连接让梯度能直接回传，层归一化让数值稳定——**没有它们，堆几十上百层会训不动**。把这样的块堆叠 N 次（GPT-3 堆 96 层，小模型 12–24 层），逐层提取越来越抽象的语义。

## 八、完整工作流程（极简版）

1. **分词 + 嵌入**：文字 → token → 向量。
2. **加位置编码**：注入顺序。
3. **多层自注意力**：全局关联语义。
4. **前馈变换**：逐词非线性加工。
5. **输出**：线性层 + Softmax 生成"下一个词"的概率分布。

## 九、给各领域从业者的结论

大模型的本质，是**基于 Transformer 架构、用注意力理解语义、在海量数据上学习规律**的深度学习系统。它不是玄学，而是一套**可解释、可复现、可学习**的工程技术体系。理解了"注意力取代逐词循环"，就理解了现代 AI 的来处（详见[07·Attention Is All You Need 精要](07-AttentionIsAllYouNeed-精要-译校.md)）。
