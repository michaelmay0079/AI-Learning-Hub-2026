# 译校 · 深度研究 Agent（改编）

> **原文**：[Deep Research Agents 2026（blocksize）](https://ai.blocksize.hr/blog/en/deep-research-ai-agents-2026)；并参考 OpenAI BrowseComp / Humanity's Last Exam（HLE）与 Anthropic 多 Agent 研究说明。
> **说明**：本篇为其中文**译校/改编**，提炼"自动研究员"的工作方式与读分方法；版权归原作者。核验日期：2026-11-09。

## 一句话定位

深度研究 Agent 是一个会**规划、搜索、阅读、写出带引用报告**的"自动研究员"——你问一个问题，它自己拆成子问题、反复上网查、读多页来源、发现矛盾再补搜，最后产出结构化报告。

## 从"一次回答"到"研究报告"

- **普通聊天机器人**：一遍过——读问题、偶尔搜一两次、直接写。
- **深度研究 Agent**：在循环里工作——拆子问题 → 搜索 → 阅读 → 发现缺口或矛盾 → 再搜 → 才动笔。报告往往数页长，附来源清单。

它能成立，靠三种同期成熟的能力合力：**推理模型**（会规划与反思）+ **可靠工具调用**（浏览、读文件）+ **长上下文窗口**（一次装下几十篇文档）。

## 产品时间线（谁先谁后）

Google 首发主流版（Gemini Deep Research，2024-12）→ OpenAI（2025-02，基于 o3）→ Perplexity（同月）→ Claude Research（2025-04）→ Mistral Le Chat（2025-07）→ Manus「Wide Research」（把任务扇出给多个并行 Agent）。

## 基准怎么读（关键）

- **BrowseComp**（OpenAI 2025-04，1266 道"难找但易验证"的题）：带浏览的 GPT-4o 仅 **0.6%–1.9%**，而 Deep Research Agent 达 **51.5%**——差距来自"架构"（规划 + 多步检索 + 综合），不是单纯模型知识。
- **HLE（Humanity's Last Exam）**（2500+ 专家级题）：OpenAI Deep Research 早期 **26.6%**，Perplexity **21.1%**；普通模型多为个位数。
- **多 Agent 为何更强**：Anthropic 多 Agent 并行研究在其内部评测中比单 Agent 高约 **90%**，代价是约 **15 倍**的 token 消耗——性能差异约 80% 可由"总推理/搜索量"解释。

## 关键提醒（务必记住）

- **有引用 ≠ 已核实**：研究 Agent 也会编造看似合理的出处；把结论当证据前，先核验关键引用（尤其学术/正式用途）。
- **工具间结论不一致处，正是你该亲自核查的地方**：同一重要问题跑两个工具对比，分歧点就是人工判断的落点。

## 给非从业者的结论

研究 Agent 把"搜 + 读 + 写"外包给一个循环，在"难找的事实"上比单纯模型知识强得多。正确用法不是盲信它的报告，而是**用它的检索能力 + 你的判断力**——跑两个工具、核对关键引用。这正是本仓库"理性速读"原则的工具化体现。
